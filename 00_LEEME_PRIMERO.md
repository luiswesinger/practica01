# SmartCampus · Kit del alumnado
**Asignatura:** Proyecto Big Data I · Taller evaluable 01  
**Duración indicada en el enunciado:** 120 minutos  
**Uso de IA:** nivel **AMARILLO** (permitido con trazabilidad)

## Por dónde empezar

1. Leed el documento completo de `01_Enunciado/` (PDF para consulta, DOCX como versión editable).
2. Utilizad `02_Datos/sensores.csv` como fuente de lecturas. El diccionario de datos explica su estructura.
3. Preparad vuestro **propio** proyecto con Docker Compose, PostgreSQL, Jupyter y Flask, conforme al enunciado. El kit no contiene una solución preprogramada.
4. Usad, si os resultan útiles, los JSON de `04_Ejemplos_pruebas/` para probar el endpoint POST.
5. Documentad el desarrollo en vuestro repositorio. `03_Plantillas/` contiene una plantilla de README y una lista de comprobación.
6. **Si utilizáis IA**, guardad desde el principio las capturas de **todos** los prompts y respuestas, también los que no funcionaron, y cumplimentad la plantilla de memoria. Debéis explicar qué falló, qué sirvió y qué cambios y pruebas realizasteis. **Si no utilizáis IA**, entregad una declaración expresa de no uso, como indica el enunciado.

## Archivos incluidos

- `01_Enunciado/SmartCampus_Enunciado_Taller_UEV.docx` y `.pdf`: instrucciones, rúbrica, bonus y norma de IA.
- `02_Datos/sensores.csv`: datos sintéticos del taller.
- `02_Datos/DICCIONARIO_DE_DATOS.md`: significado y tipos esperados de las columnas.
- `03_Plantillas/Plantilla_memoria_uso_IA_Amarillo.docx`: estructura editable para registrar prompts, capturas, errores y validación.
- `03_Plantillas/Plantilla_README_del_repositorio.md`: guion orientativo para documentar vuestra solución.
- `03_Plantillas/Checklist_de_entrega.md`: control de evidencias antes de entregar.
- `04_Ejemplos_pruebas/`: cuerpos JSON para pruebas obligatorias y un bonus opcional.

## Qué se entrega

**No se entrega este ZIP de vuelta sin cambios.** Entregad el **enlace a vuestro repositorio** con código funcional, notebook, datos utilizados, README, capturas y memoria de IA (o declaración de no uso), de acuerdo con el apartado «Entrega y evidencias» del enunciado.

**Los bonus son opcionales** y no sustituyen ninguno de los requisitos evaluables.
